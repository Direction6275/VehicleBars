# Vehicle Bars

A Retail WoW addon for players who use reversed action bar 1 bindings. It mirrors those bindings during vehicle, override, and possession bars so vehicle abilities follow the intended key order, then restores your normal bindings afterward.

Supports Blizzard and ElvUI action bars. With ElvUI, it also adds a compact, movable vehicle HUD with clickable abilities, keybind labels, cooldowns, and hover tooltips.
